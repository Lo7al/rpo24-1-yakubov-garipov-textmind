# TextMind

TextMind — учебный веб-сервис для студентов, исследователей и специалистов, которые работают с объёмными документами. Он помогает найти ответ на вопрос по загруженному PDF или DOCX и показывает фрагмент и страницу, на которых основан ответ.

## Что умеет сервис

В MVP запланированы загрузка русскоязычных PDF и DOCX с текстовым слоем до 100 страниц, ответы с указанием страницы и фрагмента и уточняющие вопросы по тому же документу.

## Стек

| Часть | Что используем |
| --- | --- |
| Бэкенд | Python, FastAPI, PyMuPDF и LibreOffice для обработки документов |
| Интерфейс | HTML, CSS, Jinja2 и HTMX |
| Локальные модели | Qwen 2.5 3B и BGE-M3 через Ollama |
| Поиск и хранение | NumPy и SQLite |
| Демонстрация | Windows-хост с Ollama, веб-приложение и доступ через Tailscale |

## Как запустить

Для подготовки среды установите Ollama и выполните:

```powershell
ollama pull qwen2.5:3b
ollama pull bge-m3
```

Команду запуска веб-сервиса добавим после сборки первого рабочего сценария.

## Структура репозитория

- `backend/` — серверная часть.
- `frontend/` — веб-интерфейс.
- `docs/` — документация проекта и файлы участников.

## Статус

Первый спринт посвящён сценарию загрузки PDF, ответа модели и просмотра источника в браузере.
